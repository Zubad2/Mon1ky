# Mon1ky
A tiny chess engine built for the [Sebastian Lague Tiny Chess Bot Challenge](https://github.com/SebLague/Chess-Challenge). Made for fun, marked at 1912 elo.

Search: 
- Principal Variation Search (PVS)
- Quiescence Search
- Iterative Deepening
- Transposition Table

Move Ordering:
- TT Move
- MVV-LVA
- Killer Moves
- History Heuristic

Eval: 
- PeSTO Evaluation
- Tapered Evaluation
- Compressed Piece-Square Tables

Time management: 
- Adaptive Time Usage
